# odin-etch-a-sketch

This project is an Etch A Sketch web application built as part of The Odin Project curriculum.

https://protokol42.github.io/odin-etch-a-sketch/

## Core Concepts Practiced

### JavaScript and DOM Manipulation

- **Dynamic Grid Generation:** Using nested loops and `document.createElement()` to build customizable grid structures on the fly based on user input.
- **Event Handling & Listeners:** Managing user interaction through `mousedown`, `mouseup`, `mouseover`, and `click` events to enable drawing and color selectiom.
- **State Management:** Tracking drawing states using a boolean flag (`mouseIsDown`) and maintaining active color and opacity modifications.

### Styling and Layout

- **Flexbox Architecture:** Structuring the user interface, control panels, and grid layouts cleanly using flexible box models.
- **Interactive UI Feedback:** Applying custom `.selected` outline states to active color palette buttons and utilizing range sliders for real-time grid adjustments.

## Technologies Used

- **HTML5:** Providing the foundational document markup structure.
- **JavaScript:** Powering dynamic grid rendering, state tracking, and drawing mechanics.
- **CSS3:** Styling the layout with flexbox, custom fonts, color palettes, and responsive range inputs.
